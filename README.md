# Non-Gate Quantum Order Finding via Coherence-Driven Closure Selection

Andrei Tudor Pătrașcu · FAST Foundation, Destin, FL 32541, USA

[Read the paper](manuscript.pdf) · [Download reproduction files](reproducibility.zip)

Identified author version of the manuscript submitted to Physica Scripta on 5 October 2026. Not an accepted or publisher-formatted article.

## What this repository contains

Closure-selection controls, protocol resource comparisons and the finite-dephasing crossover. The reported assumptions, classical controls and intermediate regime are retained.

`manuscript.pdf` is the single current reading copy. After extracting `reproducibility.zip`, `reproducibility/` contains the final scripts, required inputs, archived outputs and controls used by the paper. Source files needed to compile the paper are included where available.

## Reproducing the results

Download and extract [reproducibility.zip](reproducibility.zip), preserving its folders. Start with the README inside the extracted `reproducibility/` directory. [Verification record](REPRODUCIBILITY.md). They distinguish quick controls and reconstruction from the longer numerical campaigns. Keep the archived outputs intact and run experiments in a separate working copy. The complete package can be downloaded using GitHub's Code → Download ZIP.

This release excludes abandoned experiments, superseded drafts, private correspondence and internal working notes. Reported negative results and controls remain part of the scientific evidence.
